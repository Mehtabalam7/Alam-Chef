# MD Mushtaque Alam | Chef Portfolio

I built this responsive portfolio website for Chef MD Mushtaque Alam and delivered it to the client. It presents his culinary experience, specializations, signature dishes, services, and contact information.

I created the project using a vibe-coding workflow with Google AI Studio and GitHub Copilot.

## Features

- Responsive design for desktop and mobile
- Chef profile, career journey, specializations, creations, services, and contact sections
- Light and dark theme toggle
- Resume link

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run Locally

You’ll need Node.js and npm installed.

```bash
git clone https://github.com/Mehtabalam7/Alam-Chef.git
cd Alam-Chef
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

To create a production build, run:

```bash
npm run build
```
